# HELION starter templates

These starter blueprints are inspired by open-source MIT-licensed shadcn-style dashboard patterns and are maintained as HELION-owned starter guidance. They are used as compact generation context; generated projects remain independent.

- `landing`: hero, feature cards, CTA, footer, responsive marketing layout.
- `dashboard`: sidebar, KPI cards, chart area, filters, activity table.
- `todo`: task input, filters, task cards, empty/loading states, localStorage.
- `fullstack`: React frontend plus Express API, typed API client, health route.

See `LICENSE-MIT.txt` for the applicable MIT notice.
