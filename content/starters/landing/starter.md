# HELION landing starter

Use this as the structural baseline for a new landing page. Keep the generated app compact and production-ready.

Required shape:
- `src/main.tsx`
- `src/App.tsx`
- `src/index.css`

Design language:
- Strong hero with one primary CTA and one secondary CTA.
- Responsive feature/card grid.
- Visible trust or metrics strip.
- Final CTA and footer.
- Use semantic HTML, Tailwind utility classes, responsive spacing, and Lucide icons.
- Prefer 3-5 files for a simple request; do not create needless component files.
