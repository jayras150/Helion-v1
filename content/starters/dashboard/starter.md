# HELION dashboard starter

Use this structural baseline for dashboards and admin panels.

Required shape:
- `src/main.tsx`
- `src/App.tsx`
- `src/index.css`

Design language:
- Responsive sidebar/topbar shell.
- KPI cards with clear hierarchy and color-coded trends.
- Chart or visualization area with an empty/loading state.
- Search/filter controls and a responsive data table.
- Use accessible controls, compact spacing, and avoid flat white-only cards.
- Prefer local SVG/CSS charts when a chart library is not already present.
