# HELION todo starter

Use this baseline for task managers and productivity apps.

Required shape:
- `src/main.tsx`
- `src/App.tsx`
- `src/index.css`

Design language:
- Quick-add task form with keyboard-friendly submit.
- Active/completed filters and useful task counts.
- Task rows/cards with complete, edit, and delete actions.
- Empty, loading, and success states.
- Persist local-only state with localStorage when no backend is requested.
